# Mis Skills de Estudio y Desarrollo Profesional

Repositorio personal de habilidades de IA para aprendizaje académico,
inglés comercial y Derecho mercantil mexicano.

## Skills incluidas

### 1. Estudio escolar
Tutor para secundaria, bachillerato y universidad.
Incluye explicaciones progresivas, ejercicios, evaluaciones y técnicas de estudio.

### 2. Inglés para ventas remotas
Entrenamiento desde nivel principiante para atención al cliente,
soporte, prospección, negociación y cierre ético de ventas.

### 3. Derecho mercantil mexicano
Estudio jurídico, investigación normativa, interpretación de leyes,
análisis de casos y preparación para exámenes.

## Estructura

- estudio-escolar/
- ingles-ventas-remotas/
- derecho-mercantil-mexico/

Cada carpeta contiene un SKILL.md y materiales de referencia.

## Instalación

Consulta las instrucciones de instalación incluidas en este repositorio.
Los entornos compatibles pueden requerir ubicaciones o métodos de carga diferentes.

## Uso responsable

Las respuestas generadas deben revisarse.
En Derecho, verifica la legislación vigente y las fuentes oficiales.
En ventas, respeta la privacidad, la información comercial autorizada
y la decisión del cliente.

## Mantenimiento

Actualiza los materiales de apoyo cuando cambien los objetivos,
el programa académico, los procesos comerciales o la legislación.
